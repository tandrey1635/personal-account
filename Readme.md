# Корпоративный портал «Личный кабинет сотрудника» — профиль и показатели работы
Адаптивный веб-сайт внутренней системы для отслеживания активности, продуктивности и ключевых показателей сотрудников на чистом HTML5/SASS с семантической версткой.

## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий


## 🎯 Ключевые функции

### UI/UX элементы
- Адаптивное бургер-меню для мобильных устройств
- Профиль текущего сотрудника (активность, продуктивность, риск)
- Карточки сотрудников с онлайн/офлайн статусами и рейтингом
- Цветовая индикация роста/падения показателей (зеленый/красный)
- Таблицы с показателями


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки разработки сложных интерфейсов на чистом HTML5/SASS для внутренних систем аналитики с адаптивом и таблицами.**
